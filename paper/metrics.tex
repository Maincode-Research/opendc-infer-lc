\section{Reported Metrics}
\label{sec:metrics}

OpenDC-Infer-LC reports a single \emph{primary} metric used for ranking and a
broad set of \emph{secondary} metrics for diagnosis. All percentiles are
computed over the timed measurement window after warmup requests are excluded.

\subsection{Primary Metric: SLO-Qualified Goodput}

Let $\mathcal{R}$ be the set of requests issued in the measurement window of
duration $T$, and let $y_i$ be the number of output tokens generated by request
$i$ (re-tokenized with the declared tokenizer). Define the validity indicator
$v_i = 1$ if request $i$ is successful, not timed out, not cancelled, produces a
valid final output, and passes the quality guardrail (Section~\ref{sec:quality});
otherwise $v_i = 0$. The primary metric is
%
\begin{equation}
  \mathrm{Goodput}_{\mathrm{SLO}} \;=\; \frac{\sum_{i \in \mathcal{R}} v_i\, y_i}{T}.
  \label{eq:goodput}
\end{equation}
%
A run is \emph{SLO-qualified} only if its aggregate p95 TTFT, p95 TPOT, p95 E2E
latency, and success rate all satisfy the selected SLO profile
(Table~\ref{tab:slo}). A run that is not SLO-qualified is ineligible for the
ranked leaderboard regardless of raw throughput.

\subsection{Latency Definitions}

TTFT is the time to the first non-empty generated token. End-to-end (E2E)
latency is measured from request submission to a clean close of the response
stream. Time per output token (TPOT) for request $i$ is
%
\begin{equation}
  \mathrm{TPOT}_i \;=\; \frac{t^{\mathrm{end}}_i - t^{\mathrm{first}}_i}{\max(y_i - 1,\, 1)},
  \label{eq:tpot}
\end{equation}
%
where $t^{\mathrm{first}}_i$ and $t^{\mathrm{end}}_i$ are the first-token and
completion timestamps.

\subsection{Secondary Metrics}

Table~\ref{tab:metrics} lists the full set of secondary metrics. For multi-node
submissions we additionally report scaling efficiency
%
\begin{equation}
  \mathrm{Efficiency}(N) \;=\; \frac{\mathrm{Goodput}_{\mathrm{SLO}}(N)}{N \cdot \mathrm{Goodput}_{\mathrm{SLO}}(1)},
  \label{eq:efficiency}
\end{equation}
%
where $N$ is the number of nodes.
